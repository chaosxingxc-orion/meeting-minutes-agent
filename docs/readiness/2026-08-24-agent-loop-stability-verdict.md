# E-LOOP-STABILITY verdict

The registered experiment completed 8,574/8,574 model calls and returned
`LOOP-STABILITY-NOT-REACHED`. Structural replay passed, and L3 increased pooled
same-speaker form consistency by 11.42 percentage points versus bare. It nevertheless
beat deranged memory in only 2/4 meetings, failed convergence (`1.040 > 0.80`), increased
WER by 19.28 points, increased worst-speaker WER, and activated unsupported memory at
3.13% (`>2%`).

The result proves neither that bounded meeting memory is impossible nor that summary and
keywords are intrinsically harmful. It rejects this registered broadcast renderer:
raw recent-tail plus an extractive full-meeting summary and broad keyword inventories.
Training-free policy optimization and multimodal knowledge injection remain blocked.

The next admissible step is a separately registered sparse retrieval design that removes
raw transcript broadcast and supplies only a small per-chunk candidate set. See the
[registered read](../checks/2026-08-24-e-loop-stability-read/README.md).
