SCORING PLAN -- declared BEFORE any error rate was computed, applied
mechanically:

R1. SESSION UNIT = one transport slice (24 sessions: 6 slices x 4 meetings).
    Every arm is scored on the same 24 slice-sessions. Rationale: each slice
    was an independent request and this smoke is context-minimal by design --
    no rolling tail, no speaker-state carry -- so the core has NO means of
    keeping a speaker label stable across slices; a per-meeting permutation
    match would charge it for a capability the flight never gave it. It is
    also the only unit meeteval 0.4.3 can actually score here (plan R9).
R2. Reference, identical for all three arms of a slice:
    extract_gold_streams_for_range(resolved, start=slice.start, end=slice.end).
R3. A-grid / A-free hypothesis: parse_transcribe_attribute_response on the
    slice reply -> hypothesis_stream_from_grid_or_free_parse stamped with the
    slice bounds (real_timing=False).
R4. A-turn hypothesis: for the turn clips belonging to that slice,
    parse_transcribe_only_response -> hypothesis_segment_from_turn_reply
    (known_speaker from the frozen manifest, the turn's real absolute span).
    Empty-text replies contribute no segment and are counted as data.
R5. score_arm per (arm, slice) with default_metric_pins() (meeteval 0.4.3,
    collar 5 s). Time-constrained primary metrics are computed only where the
    committed module permits them (A-turn, real timing by construction).
R6. Aggregation is micro-averaged: per meeting over its 6 slices, per arm over
    all 24. Pooled confusion cost = (sum cp_errors - sum orc_errors)/sum(length).
R7. PRE-REGISTERED BRANCH (draft SS0), operationalized:
    d_m = CC_free(m) - CC_grid(m), CC = secondary confusion cost (cpWER-ORC-WER),
    micro-averaged within meeting m.
    "A-grid materially better than A-free" iff
      (i)   d_m > 0 for all 4 meetings (direction consistent), AND
      (ii)  pooled Delta > per-meeting spread (max d_m - min d_m), AND
      (iii) non-degeneracy guard: pooled cpWER(A-grid) <= pooled cpWER(A-free)
            -- a grid that "wins" on confusion cost only by emitting less
            transcript has not bought attribution.
    Bare rule = (i)+(ii); guarded rule = (i)+(ii)+(iii). Both are reported;
    the GUARDED outcome is the decision. Material => LISTEN main design
    CONFIRMED; not material => main design RETIRED, G1 adopts A-turn.
R8. Diagnostics: A-grid boundary respect (registered) + the same computation
    on A-free as a labelled CONTRAST; parse-mode / malformed-line counts;
    hypothesis speaker-label census; truncation (completion_tokens >=
    generation cap 1024); per-arm latency economics from the flight receipts'
    request ledgers; A-turn turn-clip time coverage of the gold region.
R9. FAIL-CLOSED metric refusal. meeteval 0.4.3 cannot always produce a number:
    it hard-refuses more than 10 speaker streams (unparameterised complexity
    guards in its cpWER and ORC-WER paths), and its MIMO matching cost
    explodes with stream count -- a whole-meeting 4-stream ORC-WER exhausted
    memory on this host. Every refusal (RuntimeError guard, MemoryError, or
    the memory cap below) is recorded as NOT COMPUTABLE for that cell, with
    its stream count and the refusal text, and the read continues.
    Consequences, mechanical:
      - a missing CC cell can never satisfy branch condition (i), which
        demands a positive delta in ALL FOUR meetings -- absent evidence is
        not evidence of a grid benefit;
      - the non-degeneracy guard (iii) is computed on the PAIRED COMMON
        SUBSET of slice-sessions where both A-grid and A-free produced a
        cpWER, so it never compares two different denominators.
    No metric definition, pin, or branch threshold was changed by this
    handling, and it was written before any error rate had been read.
