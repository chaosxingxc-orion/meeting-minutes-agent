# 2026-08-25 工作计划

## 首要目标

启动 `E-MEETING-MATERIAL-SUPPLY-AUDIT` 的零模型设计，验证与会议同时可得的官方发布稿或演示
材料，能否比单一公司身份提供更丰富、更准确的专业词纠错候选。该阶段不接触Omni，不启动
GRPO、GEPA、EM或多模态策略搜索。

## 执行步骤

1. **冻结来源边界**：仅接受官方issuer/IR域名、明确对应目标会议、发布时间不晚于会议的材料；
   记录URL、发布时间、抓取时间、SHA-256和文件类型。当前外部registry不自动视为M0。
2. **做可得性盘点**：先检查4场冻结会议是否都有release或slides；缺失项和时间证据不足项直接
   标记，不用参考转写补齐。
3. **构建零模型候选**：从材料中确定性抽取公司名、产品/业务名、缩写和字母数字术语；排除纯
   财务常用词、孤立数字和人员名单，并冻结上下文预算与去重规则。
4. **预注册一次性判读**：参考文本只负责事后计算候选precision、纠错机会、跨会议覆盖和
   false-trigger，不参与材料选择、抽取或路由。
5. **按门决策**：供给、精度、分布、泄漏和预算门全部通过后，才讨论来源准入与小型模型实验；
   任一关键门失败即归档该分支，不在已读结果上调阈值。

## 预期产物

- 来源清单与获取回执；
- 预注册、冻结配置和确定性抽取脚本；
- 一次性零模型判读与逐会指标；
- Wiki实验登记、阶段结论和是否放行模型的明确决定。

## 保持禁止

- 不使用gold/reference构造术语表或触发器；
- 不把当前模型输出的重复当作正确性证据；
- 不选择性重听，不改变固定diarizer、切片器和预处理；
- 不因材料可下载就默认其运行时合法性；
- 在稳定性与正确性门通过前，不启动training-free策略优化。
