# meeting-minutes-agent

An AI meeting-notes agent on a frozen speech-capable omni core: speaker decomposition,
per-speaker content, coreference/relation resolution, and an episode-local keyword/glossary
table statically injected back into the prompt — integrated with the interleaved listening,
spelling and revising control scheme.
